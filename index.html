Search syntax

budget reportFiles with both words. Any word (top bar) finds files with either.
"next quarter"The exact phrase (line breaks and extra spaces between the words are fine).
analy** stands for any letters: analysis, analyst, analyze. *ment works too.
gr?y? stands for exactly one letter: grey, gray. (colo*r finds color and colour.) A ? ending a word is a question mark: report?
"rep* due"Wildcards work inside phrases.
+urgentMust be there, even in Any word mode.
-draftLeaves out files (or paragraphs) that contain it. Put a minus sign in quotes to search for it: "-5".
invoice OR receiptEither word (| works too). Mix freely: tax "form 1040" OR w2 -2019.
file:*.docxOnly files whose name or folder matches (file:minutes, file:2024*, -file:old). Applies whatever the All / Any setting.
/\b\d{3}-\d{4}\b/A regular expression (JavaScript syntax; flags i, s, m), tried on each paragraph or line. It runs when you press Enter.

Whole words: cat finds "cat" but not "category" (use cat*). Turn it off to find text anywhere, as Ctrl+F does. Same paragraph / line: all the words must be in one paragraph (or one line of a text file). Curly and straight apostrophes match each other, and so do the different dashes.

Keys: Enter searches and opens the first result; F3 / Shift+F3 (or ↓ / ↑ in the box) go to the next / previous result; Esc returns to the box.

Opening the real file: a web page can't start Word or Notepad at a given spot. The sure way: type the folder's path under the file list once, click Copy path, then in Word or Notepad press Ctrl+O, paste, Enter. Copy text for Ctrl+F copies the words at the result, so in Word Ctrl+F, Ctrl+V, Enter jumps there; in Notepad, Ctrl+G and the line number shown. Open in Word tries to open the file directly, which some PCs allow and some don't.

In Word files the body, tables, text boxes, headers, footers, footnotes, endnotes and comments are searched (the last ones are shown after the body). Old .doc files and PDFs can't be read here.
